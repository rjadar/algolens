# algolens
AI-powered LeetCode companion with adaptive hints and interactive algorithm visualizations.


Learn algorithms the way a mentor teaches them.

Instead of immediately revealing the solution, AlgoLens progressively guides users through adaptive AI hints, interactive visualizations, pseudocode, and finally code.

## Vision

Solve first.
Ask for hints only when you need them.
